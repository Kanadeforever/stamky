## P0 — Manager 持久化事务

正常路径：

- [ ] 新建/删除/重命名分组；
- [ ] 添加/删除/编辑项目；
- [ ] 拖拽排序；
- [ ] Alt+↑/↓；
- [ ] 子组；
- [ ] 扫描文件夹；
- [ ] Explorer 单文件拖到左侧分组列表：加入当前高亮组，不新建组；
- [ ] Explorer 单文件拖到右侧项目列表：加入当前高亮组；
- [ ] Explorer 单文件夹拖到左侧分组列表：新建以文件夹名命名的组，并导入第一层可启动文件；
- [ ] Explorer 单文件夹拖到右侧项目列表：仅把文件夹本身作为当前组 Folder 项目加入；
- [ ] Explorer 多选文件拖到左侧分组列表：只新建一个组，内容为全部拖入文件；
- [ ] Explorer 多选文件拖到右侧项目列表：不新建组，全部加入当前高亮组；
- [ ] 拖到左侧未选中行时不会偷偷把该行当成目标组；单文件仍进入原高亮组；
- [ ] 单文件夹左侧建组扫描发生 I/O/权限错误时不创建半成品组；
- [ ] 单文件夹/多对象拖到按钮区、状态栏等非列表区域时不执行导入；
- [ ] 保存后重新启动顺序/内容一致。

2. 在 Manager 中修改项目；
3. 触发保存失败。

确认：

- [ ] 明确报错；

- [ ] UI 不继续显示“实际上没保存”的新状态；
