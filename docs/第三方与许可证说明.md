# stamky v0.9.3 第三方与许可证说明

## stamky 源码

stamky 主体为本项目独立编写的 C++20/Win32 实现。当前代码库没有把 Stacky / Stahky 源文件直接复制进 stamky 后再改名。

## 上游/灵感致谢

项目说明中明确保留以下原始名称：

- **Stacky** — https://github.com/pawelt/stacky
- **Stahky** — https://github.com/joedf/stahky

这些名称是上游项目/灵感来源，不属于 `StackyModern / stackymorden -> stamky` 的品牌迁移对象。

## Windows 系统 API

项目使用 Windows SDK/系统组件，包括但不限于：

- User32/GDI32/Common Controls；
- Shell32 / ShellLink / IShellItem / IFileOpenDialog；
- IContextMenu / IContextMenu2 / IContextMenu3；
- IPropertyStore / PKEY_AppUserModel_ID；
- COM/OLE；
- UxTheme / Msimg32 / Psapi / Advapi32 / Shlwapi / Propsys。

这些是操作系统/API 依赖，不作为第三方 runtime DLL 随项目分发。

## 图标

`src\stamky.ico` / `src\stamky_preview.png` 是 stamky 自有项目资源，不以 Stacky/Stahky 图标冒充新品牌资源。

## 语言文件

程序首次运行会释放默认 `cn.ini` / `en.ini`，只在目标文件不存在时创建，不覆盖用户自定义翻译。第三方翻译者对自己提交的译文应自行确认授权。

## GitHub Actions

Workflow 使用 GitHub 官方 Actions：

- `actions/checkout@v7`；
- `actions/upload-artifact@v7`。

它们只用于 CI 构建/上传 artifact，不链接进 stamky.exe。

## 项目许可证状态

本次发行整理**没有擅自替用户选择或新增 stamky 自身的软件许可证**。如果公开 GitHub 仓库准备采用 MIT/BSD/GPL/其他许可证，应由项目维护者明确决定并添加对应 `LICENSE` 文件；不要因为上游项目有某个许可证就自动把独立重写项目声明成同一许可证。
